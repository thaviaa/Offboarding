# Story 270088 — Replace FlyDoc with Electronic Faxing Services (Offboarding checklist)

**Sprint:** P59 · **Update set:** `MECK - AT - 270088 - EFAX TASK CHECKLIST`

## Where the items come from

`Software flow(Offboarding)` → step 2 **Application Tasks to Support Groups** always creates a Service Desk II task and calls:

```js
getTemplate('Service Desk II Support Applications (Offboarding)')  // checklist_template, by exact name
generateChecklist(template, scTaskSD)                               // copies name + order into checklist_item
```

So the change is **one data edit to the checklist template**. No script or flow change.

## Change (DEV first)

1. Make the 270088 update set current.
2. Open `checklist_template.list` → **Service Desk II Support Applications (Offboarding)**.
3. In **Template**, replace
   ```
   {"name":"FlyDoc Account","order":1},{"name":"FlyDoc Number","order":2},
   ```
   with
   ```
   {"name":"Electronic Faxing Services","order":1},
   ```
4. Don't rename the template. The script finds it by exact name.
5. Validate the JSON before saving. Invalid JSON makes `json.decode` throw, which breaks **every** offboarding request.
6. Update, then run `scripts/add_records_to_update_set.js` to capture the template.
7. Check `checklist_template.list` for Template contains `FlyDoc` in case other templates also list it.
